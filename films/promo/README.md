# LAUNCHPAD ROYALE — promo film

60 s, 1920×1080 at 60 fps, built with [filmkit](../../../filmkit) from real game footage.

| File | What it holds |
|---|---|
| `timeline.js` | Cue sheet (120 BPM, cuts on the 2 s bar grid) and the footage edit decision list (`EDL`: sub-cuts, in-points or `hit`/`hitAt` beat alignment, speed ramps, zooms, whips). |
| `footage.js` | Loads `footage/manifest.json`, seeks one `<video>` per clip to the exact frame in `film.seek(t)` (plus the next frame for slow-motion blending), draws it with zoom/punch/whip. Missing clips draw a labelled placeholder. |
| `film.js` | Shots, caption styles (Unbounded / JetBrains Mono, mint + gold), captions, flashes, overlays. |
| `score.js` | Synthesized synthwave/trap score on the same cue sheet, with its own master glue + limiter. |
| `fonts/` | Unbounded (SIL OFL 1.1, `OFL.txt`). |
| `capture/` | FootageCapture's harness that produces `footage/` (see its own files). |

`footage/` and `output/` are git-ignored: the clips are regenerated by the capture harness, the film by filmkit.

```sh
filmkit lint promo                    # caption holds, grid, safe area
filmkit sheet promo                   # contact sheet from the runtime
filmkit render promo --force          # → output/promo/launchpad-royale-promo.mp4 (+ loudness.json, spectrogram)
filmkit sheet promo --video output/promo/launchpad-royale-promo.mp4   # contact sheet from the final file
```

Swapping a take: point a logical clip at another manifest name in `CLIPS` (`footage.js`), or change the EDL entry's
`clip`/`hit` in `timeline.js`.
